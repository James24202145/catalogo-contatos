# 📞 Catálogo de Contatos

Este é um projeto de estudo desenvolvido com **Flask**, ~~**MySQL**~~ **SQLite** e **Bootstrap**. 
O objetivo é gerenciar uma lista de contatos simples, no final o aplicativo será hospedado no site <http://24202145.pythonanywhere.com/>.
O passo a passo detalhado está no arquivo `Plano_de_Ação_Gemini.md`.

- ~~MySQL~~ SQLite

- Git / GitHub
